# Architecture

`DemucsMLX` owns configuration validation, immutable native model graphs, deterministic shifts, split scheduling, memory policy, and reconstruction. `DemucsAudio` owns AVFoundation decoding, sample-rate conversion, PCM conversion, and WAV writing. The CLI composes these libraries; Python tooling is confined to development and asset conversion.

A `Separator` actor owns model instances and shape-specific compiled closures. Its graph execution phase contains no suspension points: overlapping requests cannot interleave mutation of its graph caches. Cancellation is checked between model, shift, and chunk batches. `Separator.load` performs metadata I/O and hashing in a detached task. `AudioTensor` explicitly borrows read-only array storage across Swift concurrency domains; result arrays are evaluated before crossing the actor boundary.

Hybrid transformer graphs retain FP32 convolutions, feed-forward layers, and attention projections. Only Q/K/V entering fused attention are cast to the selected attention precision. Standard residual convolution chains retain channels-last layout. The stride-four/eight-tap transposed convolution becomes a regular convolution over four cached phases. Older hybrid graphs include frequency wrapping, local attention, and framed bidirectional LSTMs; pure time models use the original factor-two Julius filters.

Repeated forward shapes compile after an eager first use. The cache is bounded to eight entries per model. Positional embeddings are also bounded. Compiled closures hold a weak model reference to avoid a retain cycle. Desktop dual streams are scoped through MLX Swift's task-local stream API; explicit array dependencies connect cross-attention layers. iOS uses one stream and a batch of one.

Split inference reuses materialized triangular windows in a bounded actor-owned cache and uses context-aware centered padding, each model's valid length, a triangular reconstruction window, and a rolling overlap-add buffer. One Metal thread gathers all contributions to one output sample in increasing frame order. No atomic addition or output-sized scatter intermediates are required. Finalized spans are evaluated asynchronously; final output is joined before return. GPU-only batches join through reconstruction. HTDemucs preserves its training length; older model tails run at their own valid lengths.

Ensemble loading reads only the current safetensors prefix. iOS retains one member; macOS retains members when the declared cache fits the memory policy. Weighted aggregation and fine-tuned single-stem selection preserve the registry's member order and Python shift RNG consumption.

Spectral framing uses a Float32 fused reflect-padding/extraction/windowing kernel, retaining MLX padding for short or unsupported inputs. A device-limited shared-memory variant is eligible at 100 MB of frame output. FFT/hop geometry is specialized; changing lengths are runtime parameters. Spectral overlap-add retains ascending summation order. Explicit actor-isolated tuning measures widths 64/128/256/512 and eligible 128/256 × 2/4-frame tiles, stores bounded version/device/shape choices best-effort, and clears compiled graphs even when interrupted. Automatic separation only reads choices.

File decode writes bounded AVAudioFile/AVAudioConverter chunks into an internally owned page-aligned planar allocation through AVAudioPCMBuffer's no-copy initializer. The completed storage is sealed and imported with MLX's managed raw-pointer finalizer; padded planes use strided views. Converter quality remains 127 and the converter drains completely. Scratch and decoder state are released before returning; caller PCM conversion keeps snapshot semantics.

A private C target reads evaluated immutable Float32/Float16 sample views with signed strides, interleaves and encodes bounded chunks, and preserves Swift's PCM16 saturation and half-away-from-zero rounding. Writers never perform MLX operations. Float32 samples pass through unchanged. A bounded AVFoundation fallback handles unsupported native writer cases. Each file is written to a sibling temporary path and published by rename; errors and cancellation remove the temporary file.

`DemucsAudio.separateAndExport` serializes model requests through one separator, bounds prefetch to one track and retains at most one pending export. Additional decoded inputs and pending output tensors share a reservation budget capped by platform and one-eighth of RAM. Large tracks fall back to serial operation. macOS defaults to one prefetch/two writers; iOS to zero/one. First errors cancel registered work, drain active tasks, release reservations and preserve completed files. Ordered reports contain paths/statistics/timings, never stem tensors. Per-track total time includes prefetch waiting; the CLI also measures complete batch wall time including session setup.

The file APIs keep the full active track and its stems in memory. GPU work is not preempted mid-kernel. Public model names are fixed to the official registry; arbitrary user architectures, sparse transformer attention and nonzero Wiener EM iterations are excluded.
